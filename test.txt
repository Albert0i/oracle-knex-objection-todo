
To create a migration: 
```
npx knex migrate:make create_todo_list
npm run migrate:make -- create_todo_list 
```

To run a migration:
```
npx knex migrate:latest 
npm run migrate:latest 
```

To rollback a migration 
```
npx knex migrate:rollback
npm run migrate:rollback 
```

To create a seed:
```
npx knex seed:make seed_todos
npm run seed:make -- seed_todos
```
To run a seed: 
```
npx knex seed:run 
npm run seed:run
```

To create migration to add more fields:
```
npm run migrate:make -- add_fields_to_todo_list
```
